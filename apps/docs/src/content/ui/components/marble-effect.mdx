# Marble Effect

A deterministic SVG avatar generator. Given the same `name`, it always produces the same marble pattern — useful as a unique, consistent identity visual without storing images.

Used internally by [Avatar](/components/avatar) as its image fallback.

## Props

<PropsTable data={[
  { prop: "name", type: "string", default: "—", description: "**Required.** Seed for the generated pattern" },
  { prop: "size", type: "number", default: "80", description: "Width and height of the SVG in pixels" },
  { prop: "colors", type: "string[]", default: "15 built-in colours", description: "Colour palette to sample from" },
  { prop: "elements", type: "number", default: "3", description: "Number of layered shapes" },
  { prop: "title", type: "string", default: "—", description: "Accessible title for the SVG (`role=\"img\"` is set)" },
]} />

All standard SVG props are also accepted.

## Accessibility

- Renders with `role="img"`.
- Provide `title` when the graphic conveys meaning beyond decoration (e.g. when used outside of an `Avatar` that already has a label).
