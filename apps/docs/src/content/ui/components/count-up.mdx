# CountUp

A number that counts up to its value when it arrives — the number beside a ring, a bar, a tile (`ui/hooks/useCountUp`, `ui/styles/motion` figures).

Three layers in one cell: the final text, invisible, holding the width so nothing beside it moves while the digits grow; the counting figure, hidden from assistive technology; and the final text again for assistive technology, there from the first moment and never changing. Only what is seen moves.

- Below the fold it waits until it is reached, then counts once.
- Under reduced motion it is the final value, and nothing is written.
- A figure the server painted is left alone when the page wakes up after the reader could already have read it: counting it back from zero would be a flash, not an entrance.

`StatTile` uses it when given `amount`.

## The hook

`useCountUp(value, ref, format)` returns the value to render — always the final one — and writes the counting into the text of `ref`, frame by frame, without a render. Use it directly only when `CountUp`'s three layers do not fit; then hide the counting element from assistive technology and give it the final value beside it.
