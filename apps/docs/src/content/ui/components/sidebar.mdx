# Sidebar

A panel that slides in from the left or right edge of the screen. Built on [Vaul](https://vaul.emilkowal.ski/) — a drawer primitive with smooth drag interaction and accessible focus management. Rendered as a client component.

### Controlled

```tsx
const [open, setOpen] = useState(false);

<Sidebar open={open} onOpenChange={setOpen} title="Navigation" trigger={<Button>Open</Button>}>
  <p>Content</p>
</Sidebar>;
```

## Accessibility

- The sidebar title is announced by screen readers when the panel opens.
- Focus is trapped in the sidebar while it is open and returns to the trigger on close.
- When the sidebar closes because a link inside it was followed, the new page should get focus, not the trigger. Prevent the return in `onCloseAutoFocus` for that close only:

```tsx
const followedLink = useRef(false);

<Sidebar
  onCloseAutoFocus={event => {
    if (followedLink.current) {
      followedLink.current = false;
      event.preventDefault();
    }
  }}
  onOpenChange={setOpen}
  open={open}
  title="Menu"
  trigger={<Button>Menu</Button>}
>
  <a href="/elsewhere" onClick={() => { followedLink.current = true; setOpen(false); }}>Elsewhere</a>
</Sidebar>;
```
- Drag-to-dismiss and `Escape` key both close the panel.

> **Note:** This is a `'use client'` component. It cannot be used in React Server Components directly — wrap it in a client boundary if needed.
