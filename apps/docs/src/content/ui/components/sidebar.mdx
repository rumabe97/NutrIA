# Sidebar

A panel that slides in from the left or right edge of the screen. Built on [Vaul](https://vaul.emilkowal.ski/) — a drawer primitive with smooth drag interaction and accessible focus management. Rendered as a client component.

## Examples

### Controlled

```tsx
const [open, setOpen] = useState(false);

<Sidebar open={open} onOpenChange={setOpen} title="Navigation" trigger={<Button>Open</Button>}>
  <p>Content</p>
</Sidebar>;
```

## Accessibility

- The sidebar title is announced by screen readers when the panel opens.
- Focus moves into the sidebar on open and returns to the trigger on close.
- Drag-to-dismiss and `Escape` key both close the panel.

> **Note:** This is a `'use client'` component. It cannot be used in React Server Components directly — wrap it in a client boundary if needed.
