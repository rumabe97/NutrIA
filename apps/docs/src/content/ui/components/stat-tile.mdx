# StatTile

One headline figure: what it is, the figure, and optionally how it moved against the previous period, a note and a sparkline (decision `0069`). The change is drawn as ▲ / ▼ and a signed percentage, and said as a sentence through `changeLabel`, so its meaning never rests on an arrow or a colour. When the previous period was zero no percentage means anything, and none is drawn.

`value` is a string: the page formats the figure. Put tiles in a list or a grid of your own; the tile is one `<div>`.

## Props

<PropsTable data={[
  { prop: "label", type: "string", default: "—", description: "**Required.** What the figure is" },

  { prop: "sparkline", type: "readonly number[]", default: "—", description: "A decorative trend beside the figure" },

Every `<div>` attribute is also accepted.

## Accessibility

- With `changeLabel`, a screen reader hears the sentence ("+12% against the previous period") instead of the drawn percentage; the arrow is `aria-hidden`.
- The colour of the change only repeats what the sign and the arrow already say.
- The sparkline is decorative.
