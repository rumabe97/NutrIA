# Tabs

A set of layered panels — only one visible at a time — activated by a row of trigger buttons. Built on [Radix UI Tabs](https://www.radix-ui.com/primitives/docs/components/tabs), which handles keyboard navigation and WAI-ARIA compliance automatically.

## Examples

### Basic

<Preview code={`import { Tabs, TabsList, TabsTrigger, TabsContent } from 'ui/components/Tabs';

export default function Example() {
  return (
    <Tabs defaultValue="account">
      <TabsList>
        <TabsTrigger value="account">Account</TabsTrigger>
        <TabsTrigger value="password">Password</TabsTrigger>
      </TabsList>
      <TabsContent value="account">Make changes to your account here.</TabsContent>
      <TabsContent value="password">Change your password here.</TabsContent>
    </Tabs>
  );
}`}>
  <Tabs defaultValue="account">
    <TabsList>
      <TabsTrigger value="account">Account</TabsTrigger>
      <TabsTrigger value="password">Password</TabsTrigger>
    </TabsList>
    <TabsContent value="account">Make changes to your account here.</TabsContent>
    <TabsContent value="password">Change your password here.</TabsContent>
  </Tabs>
</Preview>

## Accessibility

- Arrow keys navigate between tabs.
- `role="tablist"`, `role="tab"`, and `role="tabpanel"` are applied automatically.
- `aria-selected` reflects the active tab.
- `aria-controls` links each trigger to its panel.
