# Button

A clickable element that triggers an action. Supports `primary` and `secondary` variants, and three sizes.

## Examples

### Variants

      <Button variant="secondary">Secondary</Button>
    </div>
  );
}`}>

## Accessibility

Renders a native `<button>`, so role, focus, and Enter/Space activation are handled by the browser.

- **Accessible name** — provide visible text as `children`. For icon-only buttons add `aria-label="…"`.
- **Disabled state** — use the native `disabled` attribute (this component forwards it). Disabled buttons are removed from the tab order and don't fire `onClick`. If you need a button that's perceivable to assistive tech but inactive, use `aria-disabled="true"` plus a handler that no-ops instead of native `disabled`.
- **Focus visible** — the browser's focus ring is preserved; don't strip it in a wrapping CSS module.
- **Type attribute** — when used inside a `<form>`, pass `type="button"` unless the button is supposed to submit. Native default is `"submit"`, which causes accidental form submissions.
