# Image

A thin wrapper around [Next.js Image](https://nextjs.org/docs/app/api-reference/components/image) that applies consistent base styles. Inherits all of Next.js's built-in optimisations: automatic WebP conversion, lazy loading, blur placeholders, and responsive `srcSet` generation.

## Examples

### Fixed size

<Preview code={`import { Image } from 'ui/components/Image';

export default function Example() {
  return (
    <Image alt="Example image" height={200} src="https://picsum.photos/400/200" width={400} />
  );
}`}>
  <Image alt="Example image" height={200} src="https://picsum.photos/400/200" width={400} />
</Preview>

### Fill mode

<Preview code={`import { Image } from 'ui/components/Image';

export default function Example() {
  return (
    <div style={{ height: '200px', position: 'relative' }}>
      <Image
        alt="Fill example"
        fill
        src="https://picsum.photos/800/400"
        style={{ objectFit: 'cover' }}
      />
    </div>
  );
}`}>
  <div style={{ position: 'relative', height: '200px', width: '100%' }}>
    <Image alt="Fill example" fill src="https://picsum.photos/800/400" style={{ objectFit: 'cover' }} />
  </div>
</Preview>

## Accessibility

- Always provide a meaningful `alt` description. Use `alt=""` only for decorative images.
