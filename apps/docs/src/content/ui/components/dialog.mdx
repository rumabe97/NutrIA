# Dialog

A modal window that interrupts the user to request a decision or display critical information. Built on [Radix UI Dialog](https://www.radix-ui.com/primitives/docs/components/dialog), which traps focus inside the dialog, manages scroll lock, and handles `Escape` to close.

## Examples

### Basic

<Preview code={`import { Dialog } from 'ui/components/Dialog';
import { Button } from 'ui/components/Button';

export default function Example() {
  return (
    <Dialog
      closeButton={<Button variant="secondary">Close</Button>}
      title="Confirm action"
      trigger={<Button>Open dialog</Button>}
    >
      Are you sure you want to continue? This action cannot be undone.
    </Dialog>
  );
}`}>
  <Dialog
    closeButton={<Button variant="secondary">Close</Button>}
    title="Confirm action"
    trigger={<Button>Open dialog</Button>}
  >
    Are you sure you want to continue? This action cannot be undone.
  </Dialog>
</Preview>

## Accessibility

- Focus is trapped inside the dialog when open; returns to the trigger on close.
- `Escape` closes the dialog.
- Background content receives `aria-hidden` while the dialog is open.
- The dialog element has `role="dialog"` and `aria-labelledby` pointing to the title.
