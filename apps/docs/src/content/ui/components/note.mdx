# Note

Something the screen needs the reader to know, set apart from the words around it. A flat, square-cornered block on its own ground: an icon for the tone and the tone in a word, so it never rests on colour alone. It replaced the boxes with a coloured inline-start edge (project 024): there is no edge, no rounded box.

Under a field, `layout="inline"` is the same note as one line — the icon and the words, nothing around them.

It sets no role of its own. A note that must interrupt passes `role="alert"`; one that should be announced when it appears, `role="status"`.

## Accessibility

- The icon is `aria-hidden`; the tone is said by `toneLabel`, read before the words ("Error: The code has expired").
- A heading title keeps its own name: the tone word sits outside it.
- In `forced-colors`, the block keeps its shape with a line in the system's text colour.
