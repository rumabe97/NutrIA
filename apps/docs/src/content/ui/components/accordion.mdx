# Accordion

A vertically stacked set of collapsible sections. Built on [Radix UI Accordion](https://www.radix-ui.com/primitives/docs/components/accordion), which provides full keyboard navigation and WAI-ARIA compliance.

Accepts all [Radix Accordion Root](https://www.radix-ui.com/primitives/docs/components/accordion#root) props. `type` is required.

## Accessibility

- Trigger buttons are keyboard focusable and toggled with `Space` or `Enter`.
- `aria-expanded` reflects open/closed state.
- `aria-controls` links each trigger to its content panel.
