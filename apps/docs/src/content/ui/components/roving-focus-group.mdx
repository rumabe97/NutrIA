# Roving Focus Group

A low-level primitive that manages focus across a group of items using the roving tabindex pattern. Only one item in the group is in the tab order at a time; arrow keys move focus between items.

This is an **internal building block** — most of the time you want `Tabs`, `RadioGroup`, or another higher-level component that already uses it. Reach for this directly when building a custom toolbar, list, or grid that needs arrow-key navigation.

## Examples

### Horizontal (toolbar)

Tab moves into the group, Left/Right arrows navigate between buttons:

<Preview code={`import { RovingFocusGroup, RovingFocusGroupItem } from 'ui/components/RovingFocusGroup';

export default function Example() {
  return (
    <RovingFocusGroup orientation="horizontal" style={{ display: 'flex', gap: 'var(--space-02)' }}>
      <RovingFocusGroupItem asChild active>
        <button>Bold</button>
      </RovingFocusGroupItem>
      <RovingFocusGroupItem asChild>
        <button>Italic</button>
      </RovingFocusGroupItem>
      <RovingFocusGroupItem asChild>
        <button>Underline</button>

  );
}`}>

## Props

## Accessibility

- Only one item holds `tabindex="0"` at a time; the rest have `tabindex="-1"`.
- Arrow key direction is controlled by `orientation`: horizontal uses Left/Right, vertical uses Up/Down.
- Set `active` on the initially focused item so Tab into the group lands on the right element.
- `loop` wraps focus from the last item back to the first and vice versa.
