# Radio Group

A set of checkable buttons where only one can be selected at a time. Arrow keys navigate between items. Built on [Radix UI Radio Group](https://www.radix-ui.com/primitives/docs/components/radio-group) with roving tabindex for accessibility. Each `RadioGroupItem` renders a wrapping `<label>` so the visual + the label text together form the clickable target — satisfying WCAG 2.5.8 even though the visual itself is 16×16.

## Accessibility

- Arrow keys navigate between items using the roving tabindex pattern.
- `role="radiogroup"` and `role="radio"` are applied automatically.
- `aria-checked` reflects the selected state of each item.
- The wrapping `<label>` makes the label text and visual a single ~24×24+ click target — WCAG 2.5.8 (Target Size Minimum) passes via the "Equivalent target" exception even though the visual is 16×16.
