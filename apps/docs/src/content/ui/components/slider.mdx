# Slider

An input for selecting a value (or range of values) along a track. Built on [Radix UI Slider](https://www.radix-ui.com/primitives/docs/components/slider). Keyboard accessible: arrow keys step by 1, `Page Up`/`Page Down` by 10%, `Home`/`End` jump to min/max.

## Examples

### Basic

<Preview code={`import { Slider } from 'ui/components/Slider';

export default function Example() {
  return <Slider defaultValue={[40]} />;
}`}>
  <Slider defaultValue={[40]} />
</Preview>

### Range

Two thumbs for selecting a range. Pass two values to `defaultValue`:

<Preview code={`import { Slider } from 'ui/components/Slider';

export default function Example() {
  return <Slider ariaLabelThumbs={['Minimum price', 'Maximum price']} defaultValue={[20, 70]} />;
}`}>
  <Slider ariaLabelThumbs={['Minimum price', 'Maximum price']} defaultValue={[20, 70]} />
</Preview>

## Accessibility

- Each thumb has `role="slider"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and `aria-valuetext`.
- Arrow keys step by the `step` value; `Page Up`/`Page Down` by 10% of the range.
- `Home` / `End` jump to min and max.
- A single-thumb slider inherits its name from a wrapping `<label>` or an `aria-labelledby` on the Root.
- A multi-thumb (range) slider needs **per-thumb** names so each handle is distinguishable. Pass `ariaLabelThumbs={['Minimum', 'Maximum']}` — without this, both thumbs announce as just "slider".
