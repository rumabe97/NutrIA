# Code

An inline `<code>` element with monospace font, subtle background, and small padding. Use it for inline references to code identifiers, file paths, commands, and similar.

`Code` is intentionally **inline-only**. For multi-line, syntax-highlighted code blocks, there is no DS-level component yet — see the "When NOT to use" section below.

## When NOT to use Code

- **For multi-line / syntax-highlighted code** — `Code` is inline-only. There is no DS-level `CodeBlock` yet (candidate for a future addition). Until one exists, apps that need block-level code with syntax highlighting should build their own using a highlighter like Shiki or Prism. The `apps/docs` site has an internal `CodeBlock` implementation that can serve as a reference, but apps should not import directly from another app.
- **For keyboard shortcuts** — use a `<kbd>` element directly (we don't yet have a DS `Kbd` primitive).

## Accessibility

Renders a native inline `<code>`. Screen readers announce it as code, so most of the work is done for you.

- **Don't put interactive controls inside `<code>`.** It's a phrasing element, not a container — buttons, links, copy-to-clipboard widgets belong as siblings.
- **Inline only.** For block code with syntax highlighting (where reading order and language announcement matter more), see "When NOT to use Code" above.
