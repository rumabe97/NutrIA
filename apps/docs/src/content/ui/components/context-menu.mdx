# Context Menu

A menu that appears at the pointer position on right-click (or long-press on touch). Built on [Radix UI Context Menu](https://www.radix-ui.com/primitives/docs/components/context-menu), which handles positioning, portal rendering, and keyboard navigation automatically.

## Examples

### Basic

<Preview code={`import { ContextMenu, ContextMenuItem } from 'ui/components/ContextMenu';
import { Button } from 'ui/components/Button';

export default function Example() {
  return (
    <ContextMenu trigger={<Button>Right-click me</Button>}>
      <ContextMenuItem>Open</ContextMenuItem>
      <ContextMenuItem>Rename</ContextMenuItem>
      <ContextMenuItem>Delete</ContextMenuItem>
    </ContextMenu>
  );
}`}>
  <ContextMenu trigger={<Button>Right-click me</Button>}>
    <ContextMenuItem>Open</ContextMenuItem>
    <ContextMenuItem>Rename</ContextMenuItem>
    <ContextMenuItem>Delete</ContextMenuItem>
  </ContextMenu>
</Preview>

### With keyboard shortcuts

## Accessibility

- Opens on right-click or long-press; closes on `Escape` or when focus leaves.
- Arrow keys navigate between items.
- `role="menu"` and `role="menuitem"` are applied automatically.
- Menu is rendered in a portal to avoid z-index and overflow clipping issues.
