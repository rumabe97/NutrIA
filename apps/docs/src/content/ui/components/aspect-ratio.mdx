# Aspect Ratio

Constrains any content to a given width-to-height ratio. Useful for images, videos, maps, and embeds that must maintain their proportions across screen sizes. Built on [Radix UI Aspect Ratio](https://www.radix-ui.com/primitives/docs/components/aspect-ratio).

## Accessibility

Presentational only — renders a `<div>` with no inherent role. The accessibility story is whatever child you place inside:

- **`<img>` child** — `alt` is required. Decorative images use `alt=""`.
- **`<video>` child** — provide captions or a transcript.
- **`<iframe>` child** (embeds, maps) — provide a `title` describing the embedded content.
- **Background-only** (the colored-box examples above) — fine to leave unlabelled; it's purely visual.
