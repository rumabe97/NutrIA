# Select

A dropdown control for picking a single value from a list. Built on [Radix UI Select](https://www.radix-ui.com/primitives/docs/components/select), which provides typeahead search, keyboard navigation, and full WAI-ARIA compliance.

## Examples

### Basic

<Preview code={`import { Select, SelectOption } from 'ui/components/Select';

export default function Example() {
  return (
    <Select aria-label="Fruit" placeholder="Pick a fruit">
      <SelectOption indicator="✓" value="apple">Apple</SelectOption>
      <SelectOption indicator="✓" value="banana">Banana</SelectOption>
      <SelectOption indicator="✓" value="cherry">Cherry</SelectOption>
    </Select>
  );
}`}>
  <Select aria-label="Fruit" placeholder="Pick a fruit">
    <SelectOption indicator="✓" value="apple">Apple</SelectOption>
    <SelectOption indicator="✓" value="banana">Banana</SelectOption>
    <SelectOption indicator="✓" value="cherry">Cherry</SelectOption>
  </Select>
</Preview>

## Accessibility

- Opens on click or `Space`/`Enter`; closes on `Escape`.
- Arrow keys move between options; typeahead jumps to the first matching option.
- Selected value is announced by screen readers via `aria-selected`.
- Works as a native form field when placed inside a `<form>`.
