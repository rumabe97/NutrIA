# Dropdown

A button that reveals a floating menu of options. Built on [Radix UI Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu), which manages positioning, portal rendering, and full keyboard navigation.

## Examples

### Basic

<Preview code={`import { Dropdown, DropdownOption } from 'ui/components/Dropdown';

export default function Example() {
  return (
    <Dropdown label="Options">
      <DropdownOption>Edit</DropdownOption>
      <DropdownOption>Duplicate</DropdownOption>
      <DropdownOption>Delete</DropdownOption>
    </Dropdown>
  );
}`}>
  <Dropdown label="Options">
    <DropdownOption>Edit</DropdownOption>
    <DropdownOption>Duplicate</DropdownOption>
    <DropdownOption>Delete</DropdownOption>
  </Dropdown>
</Preview>

## Accessibility

- Opens on click; closes on `Escape` or when focus leaves.
- Arrow keys navigate between options; `Enter` or `Space` selects.
- `role="menu"` and `role="menuitem"` are applied automatically.
- Menu is rendered in a portal to avoid z-index and overflow clipping issues.
