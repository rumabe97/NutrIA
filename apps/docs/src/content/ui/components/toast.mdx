# Toast

Lightweight, accessible toast notifications. Built on [Sonner](https://sonner.emilkowal.ski/) — an opinionated, fully accessible toast library by Emil Kowalski with stacking, swipe-to-dismiss, and promise support.

## Setup

Add `<Toaster />` once to your root layout. It handles its own portal — no z-index configuration needed.

```tsx
import { Toaster } from 'ui/components/Toaster';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        {children}
        <Toaster />
      </body>
    </html>
  );
}
```

Then call `toast()` from anywhere in your app:

```tsx
import { toast } from 'ui/components/Toaster';
```

### Promise

```tsx
toast.promise(saveChanges(), {
  loading: 'Saving...',
  success: 'Saved successfully.',
  error: 'Failed to save.'
});
```

## Accessibility

- Each toast has `role="status"` and is announced by screen readers on mount.
- Toasts pause their auto-dismiss timer when hovered or focused.
- Swipe-to-dismiss works on touch devices.
- `Escape` dismisses the focused toast.
