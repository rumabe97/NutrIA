# Switch

A toggle control for binary on/off states. Built on [Radix UI Switch](https://www.radix-ui.com/primitives/docs/components/switch), which provides a native-like toggle with full keyboard support and WAI-ARIA compliance.

### Controlled

```tsx
const [checked, setChecked] = useState(false);

<Switch checked={checked} onCheckedChange={setChecked} />;
```

## Accessibility

- Renders with `role="switch"` and `aria-checked` reflecting the current state.
- Toggled with `Space` when focused.
- Works as a native form field when placed inside a `<form>`.
- Always pair with a visible label (via `<label>` or `aria-label`) so the purpose is clear.
