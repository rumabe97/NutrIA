# Rings

One to four concentric progress rings: the day's targets, a dish's share of the day, meals done, the plan being made. Drawn in SVG with round caps, each ring on its track, in `--color-ring-1` … `-4` over `--color-ring-track`. A value over its maximum is a full ring, never more.

Each ring sweeps to its value when it arrives (`ui/styles/motion`, figures). Rings below the fold wait until they are reached (`InView`); under reduced motion they are simply there.

## Accessibility

The text alternative is a **visually hidden list**, one item per ring ("Calories: 1,880 of 2,246 kcal"), inside a group named by `label`; the picture is `aria-hidden`. A list rather than a `role="img"` with one long `aria-label`: four figures in one label are read as a single breathless sentence that cannot be stepped through, while a list says how many measures there are and lets a screen reader move from one to the next.

When a screen draws a visible legend with the same figures, it should not also keep this list — say so to the component then, rather than reading every figure twice.
