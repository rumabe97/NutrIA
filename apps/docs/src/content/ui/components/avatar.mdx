# Avatar

A circular image frame that falls back to a generated [Marble Effect](/components/marble-effect) when no image is available. Built on [Radix UI Avatar](https://www.radix-ui.com/primitives/docs/components/avatar), which handles asynchronous image loading and prevents layout shift.

All Radix Avatar Root props are also accepted.

## Accessibility

- The loaded `<img>` carries `alt={alt ?? name}` so screen readers announce the person, not the file URL. Override with the `alt` prop when needed.
- The default marble fallback is rendered as `<svg role="img" aria-label={alt ?? name}>`, so the same accessible name is announced whether or not the image loads. Don't rely on the marble pattern conveying identity visually — it's decoration.
- When you pass a custom `fallback`, the DS hands off accessibility to you. Make sure your fallback exposes its own label (e.g. visible initials with no extra role, or `<span aria-label="…">PA</span>`).
- Radix swaps the image for the fallback after the load fails, preventing a flash of broken content.
